# Sources for the real-world held-out evaluation

All are publicly posted General Price Lists (the FTC Funeral Rule requires funeral providers to publish them). Captured 2026-11-20.
Text only was saved (gpl_<n>.txt, with a provenance header); no binaries were kept or executed. PDFs were read with pypdf (text layer only), HTML pages with a tag stripper. Site navigation/footer was trimmed from the HTML captures; PDF text is as extracted (ligatures and lost spaces are intentional test conditions).
Not included: Allay Cremation (already in data/). One candidate (CFCS Sacramento PDF) was dropped because it is a scanned image with no text layer.
